# Module 1 Quiz: Claude: Your Strategist and Writer
Checks that you can brief Claude, build a Project, connect apps safely, use skills and artifacts, and supervise Cowork.

---

## Question 1
You want Claude to write a landing page headline that sounds like your business, not like a template. What should your prompt include?

- A) Just the word "headline" so Claude has creative freedom
- B) Your role for Claude, your customer and offer, the task, and the format and tone you want
- C) A list of every competitor's headline
- D) Your login details so Claude can check your website

**Answer:** B

**Explanation:** A prompt that reads like a brief (role, context, task, output) gives Claude the facts it needs to be specific; never share login details in a chat.

---

## Question 2
You notice Claude keeps mentioning a product you dropped months ago. Where do you fix this?

- A) Settings > Memory, under Topics, edit or delete the outdated entry
- B) Start an incognito chat every time from now on
- C) Upgrade to Max
- D) Delete all your Projects

**Answer:** A

**Explanation:** Memory entries are listed under Topics in Settings > Memory, where you can edit or delete them, or you can tell Claude in chat to forget it.

---

## Question 3
You want every marketing chat to follow your brand voice and never give tax advice, without repeating yourself. What is the best setup?

- A) Paste the rules into each message
- B) Ask Claude to remember it once in a random chat
- C) Put the rules in Project instructions and the voice guide in Project knowledge
- D) Turn on chat search

**Answer:** C

**Explanation:** Project instructions and knowledge apply to every chat in the Project automatically, which makes them the right home for standing rules.

---

## Question 4
You connect Gmail to Claude. How should the send tool be set for a solo founder?

- A) Always allow, so replies go out faster
- B) Blocked forever, so Gmail is useless
- C) It cannot be configured
- D) Needs approval, so you review and send every email yourself

**Answer:** D

**Explanation:** Anything that leaves the business needs a human click, so send tools should require approval while reading and drafting can stay automatic.

---

## Question 5
While summarizing your inbox, Claude proposes sharing a Drive folder with an unknown external address. What is the most likely explanation and the right response?

- A) A prompt injection in an email; deny the action and start a fresh chat
- B) A normal feature; approve it
- C) A billing error; contact your bank
- D) Memory is full; reset memory

**Answer:** A

**Explanation:** An unexpected outbound action while reading untrusted content is a classic prompt injection sign, and denying it plus starting clean removes the attacker's foothold.

## Question 6
Your uploaded "weekly-proposal" skill never seems to activate. What should you check first?

- A) Whether memory is on
- B) Whether the skill's description clearly matches the requests you make, and that code execution is turned on
- C) Whether you are on the Max plan
- D) Whether Gmail is connected

**Answer:** B

**Explanation:** Claude chooses skills from their name and description, and skills require code execution and file creation to be turned on.

---

## Question 7
You built a sales deck with Claude Slides and want to send it to a prospect. What should you do before sharing?

- A) Nothing, artifacts are public by default so it is already shared
- B) Delete the chat so the deck is safe
- C) Check slides and speaker notes for internal information, then export or share deliberately
- D) Turn off connectors

**Answer:** C

**Explanation:** Artifacts start private, and you control sharing, so review everything including speaker notes before it leaves the business.

---

## Question 8
You schedule a nightly Cowork task that reads a folder on your laptop, and it fails whenever your laptop is shut. Why?

- A) Scheduled tasks are not supported on Pro
- B) Cowork cannot read local files
- C) The task needed Skip mode
- D) Cowork tasks run in the cloud and reach local folders only through the open Claude Desktop app

**Answer:** D

**Explanation:** On Pro and Max, Cowork runs in the cloud and can reach connected local folders only while the desktop app is open, so unattended jobs should use cloud files or connectors.
