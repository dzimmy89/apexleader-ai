# Exercise 2: Write a Reusable Prompt

:::key-concept
You'll write a five-part prompt for the task you picked in Exercise 1, test it on real material, and save the version that works.
:::

**Time:** 20 minutes · **You'll need:** an AI assistant and the material for your task · **Builds on:** Lesson 2

## Warm-up

:::checkpoint
Q: Your assistant's draft is too long and too formal. Which part of the prompt is most likely missing?
- [ ] Role
- [x] Format and an example
- [ ] Material
Why: Length and tone are set by the format you ask for and the example you show. Without them the assistant guesses.
:::

## Steps

1. Write the prompt with role, goal, material, format and example.
2. Run it. Note what you had to change in the draft.
3. Add one line to the prompt that would have prevented each change.
4. Run it again on different material and time how long the whole task takes now.
5. Save the final prompt with a clear name.

## What to bring to your session

The saved prompt, the before and after times, and one answer it still got wrong.
