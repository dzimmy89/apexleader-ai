# Module 1 Quiz: T3 Code: One Desk for All Your Agents
Checks whether you can set up T3 Code safely, send each job to the right plan, keep threads lean, and read your usage across plans.

---

## Question 1
You install T3 Code. What happens to your Claude plan's limits?

- A) They double, because T3 Code uses tokens more efficiently
- B) Nothing. T3 Code runs your existing plan, and savings come from how you use it
- C) They're replaced by T3 Code's own limits
- D) They become unlimited while T3 Code is free

**Answer:** B

**Explanation:** T3 Code is a free desk for agents you already pay for. Each job still counts against the plan of the agent doing it.

---

## Question 2
Cursor shows grey in T3 Code's provider list. What's the first thing to check?

- A) Whether you've bought T3 Code
- B) Whether Cursor is switched on in Settings → Providers and signed in on the host computer
- C) Whether your phone is paired
- D) Whether you have a Claude Max plan

**Answer:** B

**Explanation:** Cursor, Grok and OpenCode must be switched on in Settings → Providers first, and every agent must be installed and signed in on the computer running T3 Code.

---

## Question 3
You pay for Claude Pro and Cursor Premium. Where should a Claude model plan your next feature?

- A) In Cursor, since it's the same model
- B) In Claude Code, so the work counts against the Claude plan
- C) Through an API key, because it's cheaper
- D) It doesn't matter

**Answer:** B

**Explanation:** On Cursor's Premium plan, Claude and GPT models are billed at their API list price. In Claude Code, the same work uses the Claude plan you already pay for.

---

## Question 4
You switch a thread from Claude Code to Codex. What should you do first?

- A) Nothing, Codex sees everything Claude did
- B) Write a short handoff note: goal, files, decisions, done when, don't
- C) Paste your whole chat history into the new thread
- D) Start a new project

**Answer:** B

**Explanation:** Switching mid-thread is lossy. The new agent doesn't get earlier reasoning, tool calls or attachments, so a five-line note gives it what it needs.

---

## Question 5
The agent changed three files when you asked for one. What's the cheapest fix?

- A) Type "undo that"
- B) Revert to the last good message, then send a clearer prompt
- C) Switch to a bigger plan
- D) Delete the project and start again

**Answer:** B

**Explanation:** Revert restores both the files and the conversation in one click. An "undo" message costs a full turn and keeps the mistake in the thread.

---

## Question 6
You want Claude Code and Codex to edit the same site at the same time. How do you keep them apart?

- A) Tell them in the prompt to be careful
- B) Give each thread its own worktree
- C) Run both on the current checkout
- D) Use one agent with two models

**Answer:** B

**Explanation:** A worktree gives each thread its own copy and branch of the project, so neither can overwrite the other's work.

---

## Question 7
Your Usage page shows $180 of API-equivalent cost this week on your $20 plan. What does that mean?

- A) Your next bill will be $180
- B) The work would have cost about $180 at API prices, and you paid the $20 plan price
- C) T3 Code will charge the $160 difference
- D) You've been overcharged by $160

**Answer:** B

**Explanation:** API-equivalent cost shows what the same work would cost on the API. On a subscription you pay the plan price, so it's a measure of the value you got.

---

## Question 8
A friend offers a tool that rotates five Claude accounts so you never hit a limit. What do you do?

- A) Use it, since T3 Code supports several accounts
- B) Decline. It breaks the provider's terms and can get every account banned
- C) Use it only on weekends
- D) Use it with T3 Connect

**Answer:** B

**Explanation:** T3 Code deliberately doesn't pool or rotate accounts, and the course uses one account per provider. If you keep hitting limits, your Friday report tells you which plan to change.
