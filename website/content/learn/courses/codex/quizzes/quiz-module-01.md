# Module 1 Quiz: Codex: Build, Design and Automate
Checks whether you can brief Codex, run cloud tasks, make and check images, and use computer use and automations within safe limits.

---

## Question 1
A friend says they can't find the Codex app anymore. Where does Codex live in October 2026?

- A) It was shut down in July 2026
- B) Inside the ChatGPT desktop app, alongside ChatGPT Work
- C) Only in the terminal
- D) Only inside Cursor

**Answer:** B

**Explanation:** In July 2026 OpenAI merged the Codex app into a new ChatGPT desktop app where you switch between ChatGPT Work and Codex.

---

## Question 2
You want Codex to try a risky redesign without touching your current files. Which way of working fits?

- A) Local, so changes appear immediately
- B) Any mode, since checkpoints undo everything
- C) A worktree, a separate copy of the Git project
- D) Computer use

**Answer:** C

**Explanation:** A worktree isolates the experiment; if it goes badly you discard the copy and your main folder never changed.

---

## Question 3
You are setting up a Codex Cloud environment for a plain HTML site. Which network setting is best?

- A) Full internet access with all domains allowed
- B) Internet off, or the narrowest preset that lets setup work
- C) Full access plus your main email API key as a secret
- D) It doesn't matter because cloud tasks can't reach the internet

**Answer:** B

**Explanation:** The site needs nothing from the internet, so narrow access limits what the agent can reach or be misled by.

---

## Question 4
A cloud task finished and the result looks right. What's the next step?

- A) Open a pull request and merge it yourself after review
- B) Ask Codex to push straight to main to save time
- C) Copy the files by hand into your live site
- D) Leave it in the task; it's live already

**Answer:** A

**Explanation:** The pull request is your record, your review point and your undo button, and you are the one who merges.

---

## Question 5
Codex generated an icon set for your site. Which check matters most before it ships?

- A) That each icon is as large as possible for quality
- B) That every icon includes your business name in small text
- C) That the icons resemble a well-known brand so customers trust them
- D) Zoom in for odd shapes and accidental text, avoid real brands, and keep files small

**Answer:** D

**Explanation:** Generated images can contain errors and unintended likenesses, and large files slow your site.

---

## Question 6
A computer use task asks to use your banking app to check whether a client paid. What do you do?

- A) Allow once, since you're watching
- B) Choose Always allow so it can check every week
- C) Deny and stop; use an exported file instead of giving access to the account
- D) Type your bank password into the chat so it can log in

**Answer:** C

**Explanation:** Agents never move money or log into banking, and passwords never go in chat; an export gives read-only data.

---

## Question 7
Your Monday automation finds three overdue invoices. What should it produce?

- A) Draft reminder emails in a drafts folder and tell you they're ready
- B) Send reminder emails to the clients automatically
- C) Charge the clients' cards on file
- D) Post a public reminder on social media

**Answer:** A

**Explanation:** Anything that leaves the business or touches money needs a human click, so the automation prepares and you send.

---

## Question 8
Your local automation didn't run last Monday. What's the most likely reason?

- A) Automations only run in the EU
- B) Your computer was asleep or the app wasn't running
- C) Automations need computer use turned on
- D) Automations only run once and then delete themselves

**Answer:** B

**Explanation:** OpenAI notes that local automations work best when your laptop is awake and the app is running.
