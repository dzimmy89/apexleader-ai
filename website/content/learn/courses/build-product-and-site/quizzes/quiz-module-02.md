# Module 2 Quiz: Design With Agents
Checks whether you can get several on-brand versions of a screen from an agent, brief it with annotated references, and review a design before it becomes code.

---

## Question 1
Why is a Paper frame easier for an agent to build from than an image mockup?

- A) It's smaller
- B) The canvas is real HTML and CSS, so the agent can read exact sizes, colours and text
- C) Images can't be shared with agents
- D) Paper writes the whole site for you

**Answer:** B

**Explanation:** Paper's canvas is made of the same building blocks as a web page. The agent reads the frame as code, instead of guessing spacing from a picture.

---

## Question 2
You ask for four versions of your pricing page. What keeps them on brand?

- A) Asking for "on brand" in the prompt
- B) Your design system skill, with the same content in all four
- C) Picking the version with the most colour
- D) Drawing them yourself

**Answer:** B

**Explanation:** The design system skill gives every version your exact colours and fonts. Same content in each means you compare layouts, not words.

---

## Question 3
You like version A's header and version C's comparison. What's the best next step?

- A) Pick A
- B) Pick C
- C) Ask for version E combining A's header with C's comparison
- D) Start again

**Answer:** C

**Explanation:** Several versions let you merge the best parts. Picking one winner throws the rest away.

---

## Question 4
How many things should you mark on one reference screenshot?

- A) One to three
- B) At least ten
- C) None
- D) Everything you like

**Answer:** A

**Explanation:** One to three marks tell the agent exactly what matters. More and it has to guess.

---

## Question 5
Your reference is another company's pricing page. What do you ask the agent to take from it?

- A) The layout, so it's tested
- B) The words, since they convert
- C) Only the quality you marked, like spacing, in your own brand
- D) Its images

**Answer:** C

**Explanation:** References are inspiration. Layout, words and images belong to their owner. Take the quality, and let your design system skill win.

---

## Question 6
What do you do before a screenshot of your portal goes to an agent?

- A) Nothing
- B) Blur names, emails, account numbers and anything private
- C) Convert it to PDF
- D) Print it

**Answer:** B

**Explanation:** Screenshots are sent to the model. Blur anything private first; CleanShot X and most screenshot tools can do it in a click.

---

## Question 7
Why get the design critique from a fresh agent session?

- A) It's free
- B) It has no history of agreeing with you, so it isn't defending the design
- C) Only new sessions can read images
- D) The first agent is out of tokens

**Answer:** B

**Explanation:** The agent that drew the design spent the session agreeing with you. A fresh one sees only the result and the goal.

---

## Question 8
Coral on cream measures about 3 to 1. Where can you use it?

- A) Everywhere
- B) For large text and big buttons, but not small body text
- C) Nowhere; change the brand
- D) Only in images

**Answer:** B

**Explanation:** Body text needs 4.5 to 1. Large text can be 3 to 1. Keep coral for the big button and set small text in ink.
